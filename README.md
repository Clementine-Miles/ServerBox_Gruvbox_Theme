# ServerBox Gruvbox themes

Two Gruvbox palettes for ServerBox, with Light, Dark, and System appearance on FSBT schemas 3–4.

| Theme | Variants |
| --- | --- |
| [Gruvbox](themes/milesclem.gruvbox/) | Green, Blue |
| [Gruvbox Material](themes/milesclem.gruvbox-material/) | Medium, Hard, and Soft, each in Green and Blue |

Open **Settings → Appearance → Install theme** in ServerBox. Choose **Folder** on desktop or **File** to import a packed `.fsbt` on mobile. Select the variant before setting the appearance mode. ServerBox can reset the mode to System when switching variants or reimporting.

ServerBox controls SSH appearance separately. The two packages style the application UI. See the [color and compatibility notes](docs/colors.md) for terminal profiles and the ServerBox patch.

## Develop

Use Python 3.11+ and an empty preview directory outside the checkout.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install check-jsonschema==0.38.2
python tools/generate.py
python tools/release_check.py --preview-dir ../gruvbox-previews --verify-public-assets
```

The release check verifies generated bytes, runs the official schema validator and packer, checks archive reproducibility, and runs the publisher in dry-run mode. The optional asset check compares published downloads with the recorded sizes and hashes. See the [runtime and release checks](RELEASE_CHECKS.md).
